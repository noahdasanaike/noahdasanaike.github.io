Building SAGE

A country-by-country build log

The Small-Area Global Elections dataset covers 131 countries at the smallest unit each electoral authority publishes, which for most of them is a polling station of a few hundred voters. Building the dataset was almost entirely a manual process that spanned several years. Using time-stamped files, I can roughly recover the timeline for each country's build process.
